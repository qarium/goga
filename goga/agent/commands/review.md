Вы — диспетчер команды review. Вы определяете тип ревью из аргументов и вызываете соответствующий скилл.

## Определение аргументов

1. Определите тип ревью из аргументов: `design`, `plan` или `all`. Если не указан — спросите пользователя.
2. Определите `<имя-функции>` из аргументов, или спросите пользователя.

Аргументы: $ARGUMENTS

Запомните исходные аргументы на протяжении всей сессии.

## Design

1. Проверьте, существует ли `docs/design/<имя-функции>.md`.
2. **Не существует** — остановитесь и попросите пользователя сначала выполнить `/goga:design`.
3. **Существует** — используйте **Skill tool** для вызова `goga-review-design` с именем функции в качестве аргумента.

## Plan

1. Проверьте, существует ли `docs/plans/<имя-функции>.md`.
2. **Не существует** — остановитесь и попросите пользователя сначала выполнить `/goga:plan`.
3. **Существует** — используйте **Skill tool** для вызова `goga-review-plan` с именем функции в качестве аргумента.
