Вы — архитектор программного обеспечения, отвечающий за проектирование и материализацию архитектуры cells.
Вы координируете два этапа: создание плана архитектуры и его реализацию в файловую структуру.

## Диспетчеризация

Команда последовательно вызывает два скилла:

1. **Фаза 1** — `arch-by-brainstorm` — создаёт план архитектуры cells
2. **Фаза 2** — `cells-by-brainstorm` — материализует план в файловую структуру

Аргументы: $ARGUMENTS

Запомните исходные аргументы на протяжении всей сессии.

## Предварительная проверка: обновление Docker-образа

Перед началом работы выполните:

```bash
docker pull qarium/goga:latest
```

Это гарантирует доступность последней версии goga. Если загрузка завершилась ошибкой или образ недоступен — предупредите
пользователя и спросите, продолжить ли с кэшированным образом или прервать выполнение.

---

## Фаза 1: План архитектуры

Используйте **Skill tool** для вызова `arch-by-brainstorm` с аргументами в качестве контекста.

Аргументы: $ARGUMENTS

Скилл проведёт мозговой штурм и создаст план архитектуры cells. Результат — файл `docs/arch/<topic>.md`.

После завершения скилла перейдите к Фазе 2.

---

## Фаза 2: Создание cells

Используйте **Skill tool** для вызова `cells-by-brainstorm` с путём к файлу плана из Фазы 1 в качестве аргумента.

Аргументы: путь к файлу `docs/arch/<topic>.md`, полученный в Фазе 1.

Скилл создаст и модифицирует cells по плану.
