# Роутер языковых правил

Определяет язык проекта и вызывает соответствующий языковой скилл.
Применяйте спецификацию в контексте вызвавшего скилла. Не пересказывайте содержимое — используйте его
для принятия решений.

---

## Как работает

1. Прочитать файл `.goga.yml` из корня проекта
2. Получить значение поля `language`
3. Вызвать соответствующий языковой скилл из таблицы диспетчеризации
4. Если язык не поддерживается — остановиться и сообщить пользователю

## Таблица диспетчеризации

| `language` | `skill`       |
|------------|---------------|
| `python`   | `goga-python` |

Используйте **Skill tool** для вызова <`skill`>.

## Контекст вызывающего скилла

Языковой скилл предоставляет правила для:

- Команд валидации (тесты, линт, проверка фасада)
- Правил реализации фасада и реэкспортов
- TDD-протокола для текущего языка
