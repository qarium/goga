# Python: правила реализации контрактов

Языковой скилл для Python. Содержит специфичные для языка команды и правила,
используемые при компиляции дизайн-документа в план и при выполнении задач.

Применяйте спецификацию в контексте вызвавшего скилла. Не пересказывайте содержимое — используйте его
для принятия решений.

Вызывается через роутер `goga-lang-helper`.

---

## Фасад и реэкспорты

- Фасад пакета — файл `__init__.py`
- Каждое реэкспортируемое имя должно быть импортируемо из пакета через `__init__.py`
- Проверка фасада: `python -c "from package import Entity"`

## Структура файлов

- Расширение исходных файлов: `.py`
- Файлы реализуются на уровне, указанном в `CODEMANIFEST` (поле `location`)
- Тестовые файлы: `tests/test_<name>.py`

## Команды валидации

| Назначение                | Команда                                  |
|---------------------------|------------------------------------------|
| Запустить все тесты       | `pytest tests/ -x`                       |
| Запустить конкретный тест | `pytest tests/test_<name>.py -v`         |
| Линт                      | `ruff check src/`                        |
| Проверка фасада           | `python -c "from package import Entity"` |

## TDD-протокол

Конкретные команды для каждого шага протокола TDD:

1. **Контрактные тесты** — создать файл `tests/test_<entity>.py`, написать тесты
2. **Реализация** — создать/изменить `.py` файлы в `location`
3. **Верификация интерфейсов** — `pytest tests/test_<entity>.py -v`
4. **Логические тесты** — дописать поведенческие тесты в `tests/test_<entity>.py`
5. **Отладка** — `pytest tests/ -x`, исправлять реализацию, пока все тесты не пройдут
6. **Перепроверка контракта** — `python -c "from package import Entity"`
7. **Линт** — `ruff check src/`
