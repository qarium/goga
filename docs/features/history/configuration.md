# History — Configuration

The history domain reads **no section of `.goga/config.yml`** — it is configured by nothing.

The tree root is fixed at `<project>/.goga/history/`, the year defaults to the current one, and the status scale assembles from the built-in axis plus the registrations of installed tool packages (see [Hooks](hooks.md)) — none of it is configurable.

The general configuration model of the product is covered in [Configuration](../../configuration/index.md).
